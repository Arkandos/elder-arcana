# Strike Through \[Create\] \[Force\] \[Blood\] \[Chain\]
Tier 2.
Free action (Rank times / round).
Effect: You can spend an additional Success on a Strike to attack a secondary target in range. Resolve the first Strike as normal. Then make a Strike against the secondary target, using DEX+Rank to attack.

Chain: You can only use one Chain effect per action.
