# Enchant Object \[Create\] \[Esoteric\]
Tier 2. Prerequisite: [[Craft]] 3
Downtime.
Effect: You can create [[Magical Trinkets]] using magical resources and time. You require a base item to enchant, but may also create it as part of the of the same downtime activity at a -2 penalty using the [[Craft]] ability.
Once you have all the required components, make an [[Craft]] Test adding this Rank against the difficulty of creating the item. Success means the item is created without issue. Failure means the item is created with some side-effect if you spend enough silver to finish it. A botched result creates an item with a totally different effect than what was desired.

More powerful items require you to have a certain number of Ranks in this ability to create them.
