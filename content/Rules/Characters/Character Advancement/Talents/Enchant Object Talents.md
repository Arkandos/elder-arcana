# Enchant Attuned Object \[Talent\]
Tier 2. Prerequisite: [[Enchant Object]] 3. Experience Cost: 20.
Effect: You can create Attuned Items using Enchant Object. This is a lengthy downtime process that takes multiple downtime segments to complete, requires [[The Weave|Essence]] and other magical components to be created. In addition, you require access to appropriate [[Rules/Characters/Arts of Arcana/index|Arts]]. You and any number of assistants may provide the necessary Arts.

Since each Attuned Item is a unique creation, you first need to design the item and each of its attuned stages. Each stage is completed individually, and as soon as the item has one stage completed, it can be attuned to and used. You can later on continue adding more stages onto the item up to its capacity.

Since you create the item, you decide what thematic actions are needed to attune to the item.
